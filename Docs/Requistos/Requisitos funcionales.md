# RF-01. Registro de cuenta.
##3 El sistema debe permitir crear una cuenta con nombre, correo y contraseña, y verificar el correo mediante un enlace antes de usarla.
#	RF-02. Inicio y cierre de sesión. 
# El sistema debe permitir iniciar sesión, mantenerla abierta hasta que el usuario la cierre y recuperar la contraseña por correo. Antes de cerrar sesión, debe advertir que el dispositivo dejará de recibir avisos.
# RF-03. Permisos del dispositivo. 
# El sistema debe solicitar los permisos de ubicación y notificaciones, explicando para qué se usa cada uno.advertir que el dispositivo dejará de recibir avisos.
# RF-04. Invitación de contactos. 
#  El sistema debe permitir generar una invitación de un solo uso, con enlace y código, válida durante 24 horas.
# 	RF-05. Respuesta a la invitación. 
# El destinatario debe poder aceptar o rechazar la invitación tras iniciar sesión o registrarse, y el sistema debe notificarlo al usuario.
# RF-06. Gestión de contactos.
# El sistema debe mostrar cada contacto como pendiente, aceptado, rechazado o caducado, y permitir eliminarlo; un contacto eliminado deja de recibir avisos.
# RF-07. Mensaje de emergencia. 
# El usuario debe poder escribir un único mensaje de emergencia de máximo 200 caracteres; si no lo escribe, se usará «Necesito ayuda. Estoy en peligro.».
# RF-08. Inicio del aviso.
# El usuario debe poder iniciar un aviso desde la app o desde el widget; el widget no requiere abrir la app.
# RF-09. Cuenta regresiva. 
# El sistema debe mostrar una cuenta regresiva de 5 segundos, cancelable con un toque, antes de enviar el aviso.
# RF-10. Envío con ubicación. 
# El sistema debe enviar a todos los contactos aceptados el mensaje de emergencia y la ubicación actual. Si no hay contactos aceptados o no hay internet, debe informarlo y no iniciar el envío.
# RF-11.Confirmación discreta. 
# Un envío exitoso no debe emitir sonido ni mostrar textos de alerta, y se confirma con una vibración de máximo 1 segundo; un envío fallido se indica con un mensaje visible.
# RF-12. Detalle del aviso. 
# Al abrir la notificación, la app debe mostrar el nombre de quien emitió el aviso, la fecha y hora, el mensaje y la ubicación en un mapa.
# RF-13. Botón de emergencias. 
El sistema debe ofrecer, en la app y en el widget, un botón que abra el marcador del teléfono con el 911 escrito, sin iniciar la llamada.
